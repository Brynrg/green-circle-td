# Assets

This game ships **no external image/audio assets**. All graphics are drawn at
runtime on the HTML canvas (shapes + colors).

Visual identity: **Iron Rain** — procedural art inspired by Pierce Brown's
*Red Rising* / *Golden Son* (Mars dust arena, rust trenches, Gold Society
pulseArmor towers, Color-caste units). Palette and silhouettes are authored in
`main.js` / `style.css`. No third-party art libraries are bundled.

Fonts: CSS uses a system mono stack (`IBM Plex Mono` / `JetBrains Mono` /
`ui-monospace` fallbacks) — no webfont files are shipped. If a self-hosted
font is added later, document license here.
